# Portfolio Website — Laveena Panchbhai

A responsive personal portfolio built for the Full Stack Development assignment style requested.

## Included technologies
- HTML5 semantic structure
- CSS3, Flexbox, Grid, typography, animations and media queries
- Bootstrap 5
- JavaScript ES6+
- DOM manipulation and event listeners
- Arrays/objects, conditions and loops
- Client-side form validation
- Responsive/mobile navigation
- Dark mode / light mode
- Project filtering
- Project-detail modal with HTML5 video
- Animated counters
- Scroll reveal animations
- Accessible labels, alt text and skip link

## Run in VS Code
1. Extract/open this folder in VS Code.
2. Open `index.html`.
3. Recommended: install the **Live Server** extension in VS Code.
4. Right-click `index.html` → **Open with Live Server**.
5. The site will open in your browser.

## Files
- `index.html` — page structure and content
- `style.css` — all custom styling
- `script.js` — interactions and validation
- `assets/profile.jpg` — uploaded profile photo
- `assets/*-demo.jpg` — generated project preview images
- Project modals contain written project overviews only; no project videos are displayed.

## Notes
- Bootstrap and Bootstrap Icons are loaded from CDN, so an internet connection is needed for those libraries.
- The contact form performs client-side validation and then opens the visitor's email application using `mailto:`. It does not require an API key or backend.
- No FPI/API keys are used.
- Project descriptions are based on the project information supplied for this portfolio.
